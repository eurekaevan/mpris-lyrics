# Release screenshots

These images are generated from deterministic test fixtures and contain no account, notification, API key, username path, browser cookie, or live playback history.

- `panel.png` — panel lyric with the popup closed
- `popup-artwork.png` — original synchronized lyrics, artwork, metadata and progress
- `bilingual-lyrics.png` — line-aligned original and translated lyrics
- `word-sync.png` — multilingual word-sync state with a line-level translation
- `preferences.png` — Simplified Chinese GTK4/Libadwaita Preferences

The Shell screenshots use `gnome-shell-test-tool` on GNOME Shell 50.4. The Preferences image is rendered by the GTK test window itself. They are documentation assets and are intentionally excluded from the extension zip.
